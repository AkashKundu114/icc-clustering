# Manuscript Publication Figures

This directory contains high-resolution (300 DPI) figures generated for the manuscript:

- `fig0_conceptual_framework.png`: Four-panel conceptual illustration depicting (a) true signal subspace, (b) high-dimensional noise drowning, (c) Sarle's bimodality coefficient screening, and (d) inductive out-of-sample projection.

All figures can be reproduced or audited via:
```bash
python scripts/reproduce_figures.py
```
