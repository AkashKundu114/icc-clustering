# Springer Nature Manuscript Submission Suite

This unified directory contains the complete manuscript source files, style definitions, references, and publication assets formatted for **Springer Nature** journals (specifically *Data Mining and Knowledge Discovery* / DAMI) using the official `sn-jnl.cls` format.

## Repository Policy
To maintain repository compactness and comply with journal pre-publication policies:
- Manuscript LaTeX source files (`main.tex`, `sn-article.tex`, `numbers.tex`), references (`references.bib`), compiled PDFs (`main.pdf`), style definitions (`*.cls`, `*.bst`), and archive packages (`*.zip`) are **excluded from GitHub tracking** via `.gitignore`.
- Publication benchmark figures in `paper/figures/` (58 PNGs and 1 JPEG) are tracked in Git to provide empirical verification and visual validation.
- All files remain fully available and intact in the local research environment.

## Manuscript Details
- **Title:** When Do Feature Gating and Anchor Consensus Help High-Dimensional Clustering? An Empirical and Geometric Analysis
- **Target Journal:** Springer Nature Journal (*Data Mining and Knowledge Discovery* / DAMI)
- **Document Class:** `\documentclass[pdflatex,sn-mathphys-num]{sn-jnl}` (v3.1, Dec 2024)

## Local Compilation
To compile the manuscript locally using standard LaTeX tooling:
```bash
# Using pdflatex + bibtex
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Reproducing Figures and Macro Metrics
All manuscript figures and macros in `numbers.tex` are deterministically generated by the experiment suites:
```bash
# Run experiment suites to regenerate data and figures
python -m experiments.exp0_falsification.run
python -m experiments.exp1_generalization.run
python -m experiments.exp2_ablation.run
python -m experiments.exp3_real_world_benchmarks.run
python -m experiments.exp4_scalability_and_sensitivity.run
python -m experiments.exp5_extreme_scale.run

# Synchronize numbers and figure placements
python scripts/make_numbers.py
python scripts/sync_figures.py
```
