## 4. Deep Dive: Reconciliation of the Biological Subgroup Rank

### 4.1 Chronology and Cause of the Discrepancy
- In an early exploratory phase of the project, preliminary benchmark scripts evaluated a 4-dataset biological subset: Colon ($N=62$), Leukemia ($N=72$), Ovarian ($N=253$), and SRBCT ($N=83$).  
  On these four datasets, ICC-v2 achieved ranks 2, 1, 2, and 1, yielding an unweighted average rank:
  $$R_{\text{legacy}} = \frac{2 + 1 + 2 + 1}{4} = \frac{6}{4} = 1.50$$
- Later, the benchmark suite was formalized to adhere strictly to the pre-registered registry in `data/registry.yaml`, expanding the $D/N > 20$ subgroup to all **6 high-dimensional cancer datasets**:
  1. CNS ($N=60, D=7,129, D/N=118.82$): ICC-v2 Rank = 3
  2. Colon ($N=62, D=2,000, D/N=32.26$): ICC-v2 Rank = 2
  3. Leukemia ($N=72, D=7,129, D/N=99.01$): ICC-v2 Rank = 1
  4. Ovarian ($N=253, D=15,154, D/N=59.90$): ICC-v2 Rank = 4
  5. Prostate ($N=102, D=12,600, D/N=123.53$): ICC-v2 Rank = 3
  6. SRBCT ($N=83, D=2,308, D/N=27.81$): ICC-v2 Rank = 1
- True 6-dataset mean rank:
  $$R_{\text{verified}} = \frac{3 + 2 + 1 + 4 + 3 + 1}{6} = \frac{14}{6} = 2.3333... \approx \mathbf{2.33}$$
- The discrepancy arose because `experiments/make_paper_assets.py` correctly updated `paper/gen/numbers.tex` to `\RankBioICCvTwo{2.33}`, while static text strings in `springer_manuscript/main.tex` and `paper/main.tex` had retained the legacy $1.50$.

### 4.2 Verified Synchronization
During the audit remediation, all occurrences of $1.50$ in both manuscripts were replaced with the verified $2.33$:
- `springer_manuscript/main.tex`:
  - Line 65 (Abstract): `...commands Rank \#1 ($R=2.33$) on ultra-high-dimensional biological regimes ($D/N > 20$)...`
  - Line 371 (Fig 23 Caption): `...commands Rank \#1 ($R=2.33$) across the high-dimensional biomedical subgroup...`
  - Line 401 (Table 3): `\textbf{Mean Rank ($D/N > 20$ Subgroup)} & ... & \textbf{2.33}`
  - Line 414 (Sec 5.4 Text): `...attaining $R=2.33$ compared to $R=5.00$ for DEC, $R=6.33$ for Standard Consensus...`
  - Line 487 (Conclusion): `...commanding Rank \#1 ($R=2.33$) on high-dimensional biomedical regimes ($D/N > 20$)...`
- `paper/main.tex`:
  - Abstract, Table 3, and Section V text similarly synchronized.

## 5. Algorithmic Complexity Harmonization

### 5.1 Identification of Contradiction
In early revisions:
- Figure 0 Caption stated: *"closed-form inductive out-of-sample mapping that assigns unseen query instances in $O(L \cdot D)$ time without recomputing the consensus graph."*
- Section 4.3 (Equation 6) and Algorithm 1 stated: *"assigns query instances in $O(K \cdot |\mathcal{F}_{\text{active}}|)$ time by minimal Euclidean distance to calibrated cluster centroids in active subspace."*

### 5.2 Resolution
Evaluating query distance to $K$ centroids in an active subspace of dimension $|\mathcal{F}_{\text{active}}|$ requires computing $K$ Euclidean distances of dimension $|\mathcal{F}_{\text{active}}|$:
$$\text{Operations} = K \cdot |\mathcal{F}_{\text{active}}|$$
Query assignment does *not* compute distances to the $L$ anchors (that would be $O(L \cdot D)$). The caption was an obsolete artifact from an earlier prototype.  
*Remediation:* Figure 0 caption in `springer_manuscript/main.tex` (line 84) and `paper/main.tex` (line 107) was corrected to $O(K \cdot |\mathcal{F}_{\text{active}}|)$.
