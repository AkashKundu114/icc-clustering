This ledger tracks the end-to-end surgical remediation of all registered issues across Numerical Consistency (`N1`--`N12`), Methodology & Theory (`M1`--`M9`), and Experimental Design & Statistics (`S1`--`S6`) as mandated by the Project Global Rules.

**Global Rules Enforced:**
1. **Integrity First:** Every single number in the manuscript is generated from `results/results.json` into `springer_manuscript/numbers.tex` (and `paper/gen/numbers.tex`). No manual number edits.
2. **Verified by Execution:** Every claim is verified by running pytest, lint, typecheck, or experiment scripts. Command outputs are pasted into this ledger.
3. **Git Discipline:** Dedicated branch `fix/full-remediation-pipeline` with granular, atomic commits per issue cluster.
4. **Final Code Cleanliness:** Production repo code in `src/` contains zero comments; manuscript, documentation, and README retain full prose.
5. **Defensible Science:** If empirical evidence contradicts an overclaim, the claim is softened or rewritten honestly.
6. **Rigorous Statistics:** 10 seeds minimum, mean ± std reported everywhere, Wilcoxon-Holm testing with correct Critical Difference (CD) values.
