# Results Directory

This directory stores output from clustering experiments and benchmark runs executed via `scripts/run.py` or the `icc.experiments.runner` module.

---

## Directory Structure

```text
results/
└── experiments/        # JSON results files generated by experiment executions
```

## Running Experiments

To generate experiment results:

```bash
python scripts/run.py --config configs/default.yaml --output-dir results/experiments
```

To evaluate and summarize generated results:

```bash
python scripts/evaluate.py --results results/experiments/<run_name>.json
```
