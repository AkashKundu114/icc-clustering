# Dataset registry and access policy

`configs/datasets.yaml` and the loader code describe configured benchmark dataset variants and preprocessing. This directory intentionally contains no raw or cached research matrices. Registry license strings are legacy metadata, not legal determinations or permission to redistribute the exact upstream variant or its derivatives.

Read [the dataset access and rights guide](../docs/datasets.md) before acquisition or use. Check the current terms on the official source page, cite the exact variant, and do not redistribute raw data, transformed matrices, sample identifiers, or partitions until the applicable rights are established. The MIT license applies to repository software only. Yale B files must not be redistributed without Yale permission.
