# ICC 80/10/10 Holdout Evaluation

This directory contains the prespecified protocol and Loop implementation mission for paired inductive and transductive 80/10/10 evaluation.

- [Experimental protocol](EXPERIMENTAL_PROTOCOL.md)
- [Loop implementation prompt](LOOP_IMPLEMENTATION_PROMPT.md)

Track A is the primary unseen-sample generalization endpoint. Track B is a separate transductive test-subset endpoint. These results must never be pooled or described as the same task.

These documents define the experiment only. No empirical result is implied until implementation, tests, pilot/full execution and independent audit are complete.
