## 1. Context and Problem Statement

A thorough forensic audit of the historical benchmarking scripts within the ICC-Clustering repository revealed significant methodological vulnerabilities that threaten scientific validity if left unaddressed:

1. **Inflated Cohort Claims:** What was described in legacy audit scripts as a "21-dataset benchmark" contained only **6 genuine independent bulk oncology cohorts** and **1 single-cell cohort**. Over half the suite (11 datasets) comprised non-biological controls (e.g., naval acoustic sonar, spoken speech, handwritten digits), while two datasets were severely misattributed non-biological files (`MagicTelescope` astrophysics simulation and Jungle Chess endgame).
2. **Double-Counting and Duplicate Caches:** OpenML ID 1107 (`tumors_C`, Pomeroy 2002 medulloblastoma) was mistakenly indexed under two different names (`cns` and `glioma`), resulting in bit-for-bit duplicate data matrices with identical SHA-256 hashes being double-counted in benchmark summaries.
3. **Cross-Study Patient Contamination:** Ramaswamy et al. (PNAS 2001) Global Cancer Map (`GCM`, OpenML ID 1106) was benchmarked alongside Golub et al. (Science 1999) Leukemia and Pomeroy et al. (Nature 2002) CNS. Mathematical cross-correlation proved that **61 of 72 Golub Leukemia patients** ($r \ge 0.99$) and **8 Pomeroy CNS patients** were re-analyzed inside GCM, invalidating any assumption of sample independence.
4. **Concentration of Effect:** The apparent superiority of Bilateral Gated Subspace Selection (BGSS) was heavily driven by large margins in two specific datasets (Leukemia and SRBCT). Upon removing these two cohorts, the pooled effect across the remaining cohorts attenuated from $+0.1348$ to $+0.0339$ and crossed zero at the 95% confidence level.

To ensure that future revisions, extensions, and publications maintain the highest scientific rigor and satisfy the demanding peer-review standards of Springer's *Data Mining and Knowledge Discovery* (DMKD), this protocol establishes mandatory experimental standards for cross-cohort biomedical clustering evaluations.

## 2. Core Methodological Principles

```
+---------------------------------------------------------------------------------------+
|                                GENERALISATION PROTOCOL                                |
+---------------------------------------------------------------------------------------+
|  1. ONE PRIMARY RESULT PER INDEPENDENT COHORT (No duplicates, no re-partitioning)     |
|  2. COMPOSITE OVERLAP EXCLUSION (Exclude multi-study compilations with shared donors) |
|  3. TECHNOLOGY STRATIFICATION (Separate bulk microarrays, proteomics, single-cell)    |
|  4. LEAVE-ONE-STUDY-OUT (LOSO) VALIDATION (Unsupervised tuning out-of-cohort)         |
|  5. REPORTING HETEROGENEITY (Report Cochran's Q, I^2, and leave-out sensitivity)      |
|  6. INDEPENDENT PROVENANCE & CHECKSUM GATEWAY (Verified primary citations and SHA-256)|
+---------------------------------------------------------------------------------------+
```

## 3. Protocol Directives

### Directive 1: One Primary Result Per Independent Biological Cohort
- **Definition of an Independent Cohort:** An evaluation unit qualifies as an independent biological cohort if and only if it represents a distinct clinical recruitment protocol, prospective/retrospective patient cohort, or surgical accession series conducted under independent ethical oversight.
- **Prohibition of Duplicate Caching:** Identical data matrices or different feature normalizations of the same underlying accession (e.g., `cns` vs `glioma_e1`) must be collapsed into a single entity.
- **Prohibition of Multi-Label Double-Counting:** Multiple valid label partitionings of the identical physical donor set (e.g., Golub Leukemia partitioned as 2-class ALL vs AML versus 3-class AML vs ALL-B vs ALL-T) must **not** be treated as independent evaluation cohorts in macro-averages. One pre-registered primary labeling must be selected for the primary benchmark, with secondary labelings reported strictly in supplementary sensitivity tables.

### Directive 2: Composite and Multi-Study Overlap Exclusion Protocol
- **Screening for Ingested Cohorts:** Many widely cited cancer expression benchmarks (e.g., Ramaswamy et al. 2001 GCM) are multi-institutional compilations that incorporated microarrays generated by collaborating laboratories.
- **Mutual Exclusion Rule:** When evaluating a set of datasets $\{D_1, D_2, \dots, D_m\}$, if dataset $D_j$ is a composite compilation that ingests samples from primary dataset $D_i$ ($D_i \cap D_j \ne \emptyset$):
  - $D_j$ **must be excluded** from any cross-cohort generalization summary that already includes $D_i$.
  - Alternatively, if $D_j$ is evaluated, all overlapping donor samples ($r \ge 0.95$) must be masked or removed prior to computing clustering metrics.

### Directive 3: Modality and Technology Stratification
Biomedical data generated by fundamentally distinct biophysical assays exhibit radically different noise structures, sparsity distributions, drop-out characteristics, and dimensionality geometries. 

Benchmark reporting must be explicitly stratified into the following pre-defined tiers:
1. **Stratum 1: Bulk Oncology Microarrays & RNA-seq (High-D, Small-N):**  
   - Characteristics: $N \in [50, 400]$, $D \in [2,000, 25,000]$, dense continuous expression.
   - Core Cohorts: Colon (Alon 1999), SRBCT (Khan 2001), CNS (Pomeroy 2002), Leukemia (Golub 1999), Prostate (Singh 2002), DLBCL (Shipp 2002), Breast (van 't Veer 2002), Su2001 (Su 2001), Endometrium (Risinger 2003), Glioma (Nutt 2003).
2. **Stratum 2: Clinical Serum Proteomics (Mass Spectrometry):**  
   - Characteristics: High-resolution time-of-flight mass/charge ($m/z$) spectral bins; baseline drift, chemical noise.
   - Core Cohort: Ovarian Proteomics (Petricoin 2002, SELDI-TOF).
3. **Stratum 3: Single-Cell Transcriptomics (scRNA-seq; Moderate/High-N, Extreme Sparsity):**  
   - Characteristics: $N \in [500, 70,000]$, $D \in [500, 30,000]$, $>80\%$ zero-inflation / drop-out, Poisson/negative binomial noise.
   - Core Cohorts: Zheng 68k PBMCs (Zheng 2017), Muraro pancreas (Muraro 2016), Zeisel cortex (Zeisel 2015).
4. **Stratum 4: Non-Biological Negative Controls (Tabular, Sensor, Vision, Speech):**  
   - Characteristics: Physical sensor time series, computer vision pixels, text TF-IDF.
   - Permitted Role: Used strictly as methodological controls to assess whether algorithm assumptions hold outside molecular biology; **strictly prohibited from being pooled into biological oncology macro-averages**.

### Directive 4: Cross-Cohort Validation & Hyperparameter Hygiene
- **Unsupervised Model Selection:** In unsupervised clustering, evaluating test-set performance using hyperparameters tuned on the ground-truth labels of that same dataset constitutes methodological information leakage.
- **Frozen or Out-of-Cohort Tuning:** All algorithmic hyperparameter settings (e.g., ensemble size $M$, anchor budget $m$, temperature $\tau$, feature gating variance threshold $\gamma$) must be either:
  1. Fixed globally based on theoretical defaults or prior literature (e.g., $M=50, m=\lfloor\sqrt{N}\rfloor$).
  2. Selected purely via unsupervised internal criteria (e.g., consensus stability, gap statistic, silhouette index, ICC-AutoK).
  3. Tuned strictly on a disjoint development cohort using Leave-One-Study-Out (LOSO) cross-validation.

### Directive 5: Transparent Heterogeneity and Non-Universal Benefit Reporting
- **Acknowledge Non-Uniformity:** Biological cancer types vary widely in signal-to-noise ratio, driver gene sparsity, and cluster separation. No single clustering method dominates across all biological geometries.
- **Mandatory Meta-Analytic Reporting:** For any proposed method claiming superiority over standard baselines:
  - Report per-cohort paired differences ($\Delta \text{ARI} = \text{Proposed} - \text{Baseline}$).
  - Report DerSimonian-Laird Random-Effects pooled effect and 95% confidence interval.
  - Report Cochran's $Q$ test statistic, degrees of freedom, and $p$-value.
  - Report Higgins & Thompson $I^2$ heterogeneity index.
  - Report Leave-One-Cohort-Out (LOCO) sensitivity bounds.
  - Explicitly report Leave-Out analyses for any cohorts exhibiting unusually high effect sizes (e.g., Leave-Leukemia-and-SRBCT-Out).

### Directive 6: Provenance, Checksums, and Data Traceability Gateway
Every dataset incorporated into the repository or cited in the manuscript must pass an automated provenance gate (`scripts/cohort_audit/verify_provenance_gate.py`):
- **Verification Requirements:**
  1. Primary peer-reviewed journal citation (Author, Year, Title, Journal).
  2. Permanent Digital Object Identifier (DOI).
  3. Official public accession number (GEO, ArrayExpress, SRA, or OpenML).
  4. Explicit clinical cohort origin (institution, sample tissue, patient eligibility).
  5. Exact SHA-256 cryptographic checksum of raw and preprocessed arrays recorded in `data/registry.yaml`.
  6. Automated pipeline capable of downloading and rebuilding the dataset from primary source without manual intervention.
