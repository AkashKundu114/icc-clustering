# Research results and release status

This repository snapshot does not distribute a numerical result table or the run-level records used in the local stability analysis. A historical local reconstruction reported descriptive stability/alignment differences, but the producer and execution history are unauthenticated and the scalar summaries, partitions, caches, and other derived artifacts have not been cleared for redistribution. The values are therefore withheld here; this is an evidence and rights limitation, not a claim that the observed pattern was absent.

The six-cohort investigation compares pairwise agreement among subsampled partitions with ARI to supplied reference labels. It is a saved-output reconstruction, not a fresh execution of the original clustering fits. No public artifact in this snapshot allows an independent researcher to regenerate that analysis.

The 13-dataset benchmark is a separate external-ARI score comparison. It is not a 13-dataset stability analysis. Its execution lineage and method-comparability evidence are incomplete, so the repository does not present it as authenticated independent fit records or evidence of ICC superiority.

When source-specific data rights and result provenance are established, a future result package should include source/configuration identity, inputs, checksums, computation script, output schema, and a clean-clone test. Until then, no numerical research results are represented here as independently reproducible public outputs.
