# Experiment provenance

## Historical six-cohort protocol

The protocol-producing script for the six-cohort stability study is available in [Git commit `49f3882`](https://github.com/AkashKundu114/icc-clustering/commit/49f3882fe5385913a9af1a5b89138c6ae6d95579). It specifies the experimental loop and output format. Finding that source does not establish that the historical partition and fit-record files were generated by it.

The historical files have no contemporaneous execution manifest that binds their bytes to an exact code commit, cache hash, sample-identifier map, runtime environment, or invocation. The configured cohort caches do not preserve stable upstream sample IDs. Consequently, protocol-source recovery and historical execution authentication are separate claims; only the former is supported by the public Git history.

## Later local run

A new full six-cohort run was executed locally on 2026-11-02 from the recovered protocol source. The input caches, partition assignments, fit records, and numerical outputs are not part of this public repository. Rights for the exact configured inputs and derived artifacts have not been cleared. The run therefore cannot be independently inspected or reproduced from a clean clone, and it does not retroactively authenticate the historical execution.

## Thirteen-dataset score benchmark

Saved benchmark score rows were reaggregated locally and the rank calculation was independently checked. The original score-generating fit events, per-method implementation fidelity, and data-use permissions were not authenticated by that arithmetic check. Score inputs and numerical aggregates are not included in this repository pending rights review. This external-ARI comparison is distinct from the six-cohort stability analysis.

## What a provenance-complete release would require

A future authorized research-data release should bind each run to the exact source commit and configuration, dataset version and permitted input hashes, stable sample mapping where allowed, preprocessing fingerprint, random seeds, subsample indices, model outputs, failure records, environment, start/end times, and output checksums. Until those elements and the relevant redistribution rights are established, this repository makes no claim that historical model execution is authenticated or that the research-result package is publicly reproducible.
