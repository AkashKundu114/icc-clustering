# Limitations

- **Small cohort set:** the stability analysis covers six biomedical cohorts. The cohorts are not a probability sample; broad biomedical population inference is not supported.
- **Sampling is not initialization robustness:** the recorded model seed is fixed. The stability calculation reflects variation under saved sample subsets at one initialization setting.
- **Reference labels inform design:** the reference labels were used for class-stratified sampling and to set requested K. The evaluation is not fully label-blind. ARI quantifies agreement with these operational reference categories, not clinical validity or a complete biological truth.
- **Dependent observations:** 435 pairwise ARIs reuse partitions and observations. Seventy-two method-by-cohort cells share six cohorts, method labels, and sampling design. They are not independent cohort replications.
- **Historical provenance:** a partition-writing protocol implementation first appears in tracked history after the observed local filesystem timestamps of the saved partitions and per-fit records. Those timestamps are not authenticated creation records, and no earlier producer was found in the tracked history or ten searched local archives. No contemporaneous execution trace or generation-time input hashes were found. The actual historical producer remains unidentified; the later source does not authenticate historical execution.
- **Duplicate outputs:** three priority cross-method/cross-mode duplicate pairs were regenerated byte-for-byte in a later local full run using cache files whose hashes matched the recorded run inputs. This shows the later implementation can reproduce those coarse or degenerate assignments and makes output collapse plausible. Because the historical producer and invocation are not authenticated and the evidence files are not public, the origin of the historical duplicates remains unresolved; they are not treated as proof of either benign convergence or file corruption.
- **Benchmark fairness:** the 13-dataset benchmark has incomplete run-level provenance, different seed schedules and computational budgets, heterogeneous implementations, and ambiguous failure status for some zero scores. Its reported comparison is descriptive/exploratory.
- **Access and redistribution:** most data and derived artifact rights remain unresolved. Yale B imagery may not be redistributed absent permission.
- **Public reproducibility:** a full six-cohort run was completed locally, and a separate saved-score table recalculation was executed, but their inputs and run outputs are not in this public snapshot. Dataset and derived-artifact rights remain unresolved. Partition-level reproduction is unavailable from a clean clone, and the historical execution provenance remains unverified.
- **Software claims:** the code repository contains many methods and utilities, but audited performance evidence does not establish universal superiority, clinical usefulness, causal mechanisms, or universal scaling guarantees for ICC.
