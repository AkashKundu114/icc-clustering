# Support and Inquiries

Thank you for your interest in the Inductive Consensus Clustering (`icc`) codebase and research framework.

---

## 1. How to Get Help

- **Documentation:**
  - [Peer Reviewer & Reproducibility Guide](docs/REPRODUCIBILITY.md)
  - [API Reference](docs/api.md)
  - [Theoretical Foundations](docs/THEORETICAL_FOUNDATIONS.md)
  - [Dataset Guide & Licenses](docs/DATA.md)
  - [Hardware & Software Environment](docs/ENV.md)

- **Bug Reports & Issues:**
  If you find a bug, unexpected behaviour, or an error:
  - Check the [Issue Tracker](https://github.com/AkashKundu114/icc-clustering/issues) to see if it has already been reported.
  - File a new issue with a minimal reproducible code snippet, input data shape, seed, and your environment specifications (`python -V`, `pip list`).

- **Reproducibility Inquiries:**
  If you encounter discrepancies reproducing any benchmark table or figure:
  - Consult the [Peer Reviewer & Reproducibility Guide](docs/REPRODUCIBILITY.md).
  - Verify single-thread linear algebra determinism (`export OMP_NUM_THREADS=1`, `export MKL_NUM_THREADS=1`).
  - Execute `python tools/check_consistency.py` to confirm baseline invariant integrity.
