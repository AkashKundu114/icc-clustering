# Prospective run validation

## Validation executed

Command: python -m unittest discover -s audit/loop6_0/provenance/tests -v

Result: 4 tests passed, exit code 0, Python 3.14.6, NumPy 2.4.6. Tests cover a valid synthetic partition trace, duplicate run-ID rejection, partition hash-mismatch rejection, and acceptance of an empty manifest. These are software integrity tests only; no empirical fit occurred.

The validator is scripts/validate_run_manifest.py. It checks unique run IDs, lowercase SHA-256 fields, status values, path containment, partition hash, NPY schema (sub_idx, labels), index uniqueness/range, lengths, observed K, cluster sizes, and hashes of indices/assignments. The prospective schema is execution_trace_schema.json. The validator reads object NPY with allow_pickle=True; only run artifacts generated by the trusted experiment process should be validated this way. Never use it on untrusted NPY files.
