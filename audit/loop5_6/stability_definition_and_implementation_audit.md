# Stability definition and implementation audit

Historical script `scripts/stability_subsample.py` and its protocol were inspected, and saved outputs were recomputed. For each cohort, method, and mode, 30 class-stratified, without-replacement 80% subsamples were generated using split seeds 5000–5029. Actual sizes are floor(0.8N): 48, 49, 57, 202, 81, 66 for CNS, Colon, Leukemia, Ovarian, Prostate, SRBCT. Splits are generated once per cohort/repeat and reused across methods and real/null runs.

For each of 30 partitions, external alignment is ARI between its predicted labels and reference y restricted to the same retained row indices. Stability is the arithmetic mean of ARI over all C(30,2)=435 pairs of predicted label vectors, each restricted to the intersection of their retained row indices. ARI is permutation invariant; no label matching is needed. The 435 pair values are dependent: they reuse partitions and often share samples. They are not independent replicates or an inferential sample size. The per-repeat ARIs and pairwise stability calculations are paired to the same cohort/method and split schedule; there are 30 accuracy observations and 435 derived pair comparisons per cell.

Reference labels determine the stratified sampling, so the perturbation population is label-informed even though y is not passed to clustering. Fixed model seed 0 means repeated perturbation assesses sample/subsample sensitivity, not random initialization sensitivity. Algorithm budgets differ by method. Overlapping draws are extensive; saved outputs show one unique split pattern across methods for each cohort/repeat (shared by design), while overlap between repeat pairs varies.

Potential effects: ARI can reward coarse or imbalanced partitions depending on data and K; pairwise ARI on intersections can change the evaluated population from pair to pair. Different target K values (2 except SRBCT K=4) affect difficulty. Singleton/missing-sample behavior is intersection restriction; no missing row is imputed. Fit exceptions are converted to all-zero labels and accuracy zero in the historical routine, and aggregation does not filter status, but all 4,320 recovered records report success, so this path did not affect this run. Permuted null independently permutes feature columns per repeat using seeds 6000+repeat, so cross-repeat null stability compares distinct null realizations.

**Judgment:** reconstructed implementation is internally consistent with the saved records and measures reproducibility under this specific stratified subsampling protocol. It is not a general stability property, independent-replicate estimate, or algorithm-seed robustness assessment.
