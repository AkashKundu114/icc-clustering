# Unresolved evidence and reproducibility gaps

1. **Input lineage:** `X`/`y` caches are present and their hashes match between the two local project directories, but they contain no accession, sample ID, preprocessing metadata, or matrix/label hashes recorded in the fit rows. Recomputed ARI confirms internal alignment of each cache and saved outputs; it cannot prove the original run loaded those exact bytes.
2. **Sample identity/order:** partitions store row indices only. They pair correctly to the currently recovered cache order and use identical indices across methods and modes, but there is no stable identifier crosswalk to the source cohort records.
3. **Public availability:** the current target repository’s clean checkout does not contain the cache, run, or partition files. In `D:\Final Year Project`, the 4,320 Parquet and 4,320 NPY files and the caches are ignored. Only aggregate summaries and scripts/protocol were versioned at a historical commit. No public archive/DOI containing the recovered run-level files was found.
4. **License status:** cached cohort arrays and external labels are third-party-derived. This search found source links/configuration claims but no source-specific redistribution permission covering all six datasets and transformed matrices. Do not include caches in a public package until permissions and attribution are cleared.
5. **Protocol caveats:** subsamples are stratified using reference labels, although labels are not passed to the clusterer; fits use a fixed algorithm seed (0), so the perturbation repeats vary samples rather than algorithm seeds. The 435 pairwise ARIs share partitions and overlapping samples and are dependent. The null procedure independently permutes feature columns with a different null seed for each repeat, so null stability reflects both row resampling and replicate-specific column permutations.
6. **Degeneracy-rule timing:** the historical protocol confirms the 5%/90% threshold was added post hoc after the CoreHalo prostate collapse. It is reproducible from the recovered partitions but must remain exploratory/conditional. The 20 Rule (i) flags and 18 Rule (i′) cells must not be conflated with the selected nine-cell Rule (iii) subset.
7. **Potential code-path bias:** the historical fit routine converts exceptions into all-zero labels and zero accuracy, while the compiler averages run accuracies without filtering failed status. No failures occurred in the recovered 4,320 records, so this bug does not affect this recovered run; it remains a risk in the implementation for other runs.
8. **Execution environment:** the parquet records do not store complete package versions, source commit, configuration hash, input hash, or hardware. The run’s protocol and script version are recoverable, but an identical environment cannot be reconstructed from each record alone.
9. **Summary history bytes:** the current FYP and `icc-clustering` summaries are byte-identical. The experiment commit’s tracked CSV has a different raw SHA-256 because of line-ending serialization; after CRLF normalization, the content matches. SHA-256 and Git blob SHA-1 are reported separately in the manifests.
