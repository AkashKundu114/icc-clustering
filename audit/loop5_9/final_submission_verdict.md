# Final DMKD submission verdict — Loop 5.9

## Executive decision

# **HOLD**

The narrow six-cohort stability–accuracy observation is numerically supported as a descriptive reconstruction from locally recovered files. Material issues remain in historical provenance, bootstrap interpretation, manuscript claim scope, benchmark fairness, clean reproducibility, data rights and manuscript version control. This decision does not claim the central arithmetic is false; it declines submission certification.

## Explicit answers

1. **Does the central result survive?** Yes as a bounded descriptive observation from recovered local partitions. It is not an inferential law or universal validity metric.
2. **Are the 4,320 saved runs/partitions internally consistent?** The independent Agent A scan and lead reconstruction indicate complete matched records, success statuses and no malformed/missing entries. Internal consistency does not authenticate model execution.
3. **Can historical execution be authenticated?** No. The producer and execution trace were not recovered.
4. **Are the duplicates explained?** No. All 140 groups must remain “cannot classify”; K=1 cases are plausible degeneracy, and the nontrivial Prostate 80/1 pair is unexplained.
5. **Are nine cells defensible?** Only as a post-hoc exploratory supplementary result; not an independent confirmation.
6. **Is the CI aligned with .485376?** No. The point is cell-weighted; the historical interval is equal-cohort. Loop 5.9 additionally found seed/order dependent bootstrap endpoint variants. Omit interval from primary claims.
7. **Are 3,000 benchmark rows verified?** Yes, as saved records and recalculated statistic. No, as 3,000 independent model executions: rows include copied/imported scores and execution provenance is incomplete.
8. **Is ICC-v2 superior?** Unsupported. Rank 4/12 and nonsignificant Friedman do not establish superiority, equality or robustness; comparisons have methodological fairness limits.
9. **Can reviewers reproduce the experiments from a clean clone?** No. Public Tier 1 aggregate arithmetic only; Tier 2 fails for missing artifacts and Tier 3 was not run.
10. **Are all claims supported?** No. The canonical local source contains substantial ablation, causal, theoretical, scalability, interpretability, biological and clinical claims not audited from raw evidence.
11. **What blocks submission?** Exact manuscript not committed/confirmed; CI and subset language wrong/ambiguous; execution provenance absent; duplicate outputs unexplained; 3k fit wording/fairness overstated; full release absent; rights unresolved; other headline claims unaudited; manuscript did not compile in this environment.

## Required work before submission reconsideration

1. Freeze and commit the exact intended manuscript, bibliography, tables, figures and supplement; compile from a clean environment.
2. Revise abstract, contribution and conclusion to the six-cohort descriptive claim; remove primary CI and post-hoc confirmatory phrasing; disambiguate 18-cell sets.
3. Correct saved benchmark row vs fit count, seed schedules and comparison limitations; remove ICC superiority/generalization language.
4. Resolve or transparently disclose producer/run provenance and all duplicate groups; if impossible, undertake prospective rerun with immutable per-fit hashes and label it as new.
5. Independently audit high-risk ablation, simulation, theory, Prostate, clinical and scaling claims.
6. Complete dataset and derived-artifact rights review; build only a cleared package.
7. Publish an immutable release and pass Tier 1; Tier 2/3 must be claimed only if they actually run in a clean clone.
